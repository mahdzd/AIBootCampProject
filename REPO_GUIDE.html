🚀 Getting Started

  1. Clone the repository: git clone <url>
  2. Read the README: cat README.md
  3. Install dependencies: pip install -r requirements.txt
  4. Run training: python resnet9_starter.py
  5. View results: python visualize_results.py
  6. Compile report: pdflatex PROJECT_REPORT.tex
